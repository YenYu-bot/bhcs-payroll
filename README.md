# 百宏文教機構 · 薪資試算系統

零依賴單一 HTML 薪資工具（`index.html`），直接以瀏覽器開啟或部署於 GitHub Pages。

## 功能
- 月薪／計時員工；每週七天各自排班（工作日、未排班、休息日、例假日），平時／暑假／寒假三組時間；2026 年勞健保級距、勞退自提與雇主提繳
- 出勤日曆可直接輸入上下班時間計算工時、依排班產生應出勤日、休息時間扣除
- 自訂薪資項目：員工固定加減項（可計入工資基礎）與本月加減項
- 遲到早退可依員工申請以特休時數抵扣（15／30／60 分單位，需審核）
- 打卡機 `.xlsx` 匯入：應出勤日曆、漏打卡、未打卡待確認、遲到早退、缺勤時數
- 加班費逐日計算（平日、休息日、國定假日，§24、§39），定額加班費自動比對法定金額
- 請假：病假（年度 30 日半薪上限）、生理假、事假、家庭照顧假、婚喪公假、曠職
- 全勤獎金依勞工請假規則 §9（病假按比例、受保護假別不影響）
- 特休：週年制／曆年制、遞延、年度終結與離職未休工資（§38、施行細則 §24-1）
- 系統自動計算／更正補足的金額一律人工審核（通過／不採用），審核完才能確認
- 薪資單確認鎖定並列入「薪資紀錄」，異動紀錄記下所有審核、確認、修改
- 密碼保護：PBKDF2 + AES-GCM 加密存放於本機，備份檔同樣加密，閒置 15 分鐘自動鎖定
- Excel 總表、Word 薪資單、年度薪資紀錄、列印

## 資料
所有資料只存在使用者瀏覽器的 localStorage（按月份分開），不會上傳。建議啟用密碼保護：GitHub Pages 同一網域（yenyu-bot.github.io）下的其他網頁可讀取同一份 localStorage，加密後才無法讀取。請定期用「匯出備份 (JSON)」備份；忘記密碼無法復原。

本工具僅供試算，實際仍以法令、主管機關函釋與專業意見為準。
